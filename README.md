# AshkanTravel

A modern travel website built with **Vue 3** and **Vite**, designed to provide a smooth and visually engaging experience for exploring tours, viewing trip details, and completing bookings.

## 🚀 Overview

AshkanTravel is a frontend travel platform focused on presentation, usability, and interaction.  
It allows users to browse tours, search and filter destinations, view detailed travel information, save favorites, and simulate a booking flow.

The project emphasizes:
- Clean and responsive UI
- Modern frontend architecture
- Strong user experience
- Support for both RTL and LTR layouts

## ✨ Key Features

- **Tour Listing:** Browse available tours in a structured and responsive layout
- **Search, Filter, Sort, and Pagination:** Easily find tours based on user preferences
- **Tour Details Page:** View full information, itinerary, and booking-related details
- **Booking Form:** Simulated reservation flow with user-friendly input handling
- **Favorites:** Save preferred tours using persistent LocalStorage
- **Dark Mode:** Comfortable viewing experience in different lighting conditions
- **RTL/LTR Support:** Flexible layout for multilingual or international audiences
- **Toast Notifications:** Clear feedback for user actions

## 🛠️ Tech Stack

- **Framework:** Vue 3
- **Build Tool:** Vite
- **Styling:** [Tailwind CSS / CSS / SCSS]
- **State Management:** [Pinia / Vuex / Composition API]
- **Routing:** Vue Router
- **Forms:** [VeeValidate / native form handling]
- **Code Quality:** ESLint, Prettier, Husky
- **Storage:** LocalStorage

## 🎨 Design Philosophy

This project was designed around a few core principles:

- **Trust:** Blue tones to create a professional and reliable travel experience
- **Calm & Nature:** Green-blue accents to reflect travel, relaxation, and exploration
- **Action:** Amber highlights for important buttons and booking actions
- **Accessibility:** Dark mode and responsive layout for better usability
- **International Ready:** RTL/LTR support for broader audience compatibility
